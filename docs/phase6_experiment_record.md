## 2. 技术选择

- Python 3.10或更高版本；
- `PyMySQL==1.1.1`，通过OceanBase MySQL兼容协议连接；
- 项目专用 `.venv-phase6`，不修改系统Python；
- Bash入口隐藏读取一次数据库密码；
- 数据库密码写入 `/tmp` 下权限600的临时文件，通过文件路径传给Python，退出时删除。

选择PyMySQL是因为它为纯Python轻量驱动，不需要编译本地扩展，适合WSL课程实验和后续批量数据、并发脚本复用。

## 3. 业务功能

1. 用户注册；
2. 创建机主和多个手机号；
3. 一个订单购买多个面额、多张充值卡；
4. 卡号和密码校验后为手机号充值；
5. 查询用户购卡明细视图；
6. 查询手机号充值历史视图。

## 4. 事务策略

生产CLI通过事务上下文实现成功COMMIT、异常ROLLBACK。购卡服务在同一事务内写入订单、明细和所有卡。充值服务先用 `SELECT ... FOR UPDATE` 锁定卡行，校验凭据后只插入充值记录；阶段5的BEFORE触发器执行最终金额/状态检查，AFTER触发器更新卡状态和使用时间。

自动实验使用一个外层测试事务，各业务场景用SAVEPOINT隔离。购卡中途故意制造重复卡号约束失败，然后回滚到SAVEPOINT并检查订单和卡均为0。全部测试完成后回滚外层事务，再用新连接验证P6残留为0。该方式不需要删除已提交数据，最适合当前RESTRICT外键和触发器结构。

- 所有业务值使用PyMySQL参数化占位符 `%s`；
